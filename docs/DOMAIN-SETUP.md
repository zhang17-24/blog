# 域名备案与 HTTPS 切换指南

> 域名 `claspmoon.cn` → 服务器 `<服务器IP>`
>
> 当前状态：**域名已实名认证，备案未完成，站点通过 IP + HTTP 正常访问**

---

## 0. 一句话结论

域名本身没有任何问题，但**备案是硬门槛** —— 未备案的域名指向腾讯云大陆服务器，
80/443 会被腾讯云的未备案监测系统拦截，访客看到的是腾讯云的提示页而不是你的博客。

而备案目前卡在一个**前置条件**上：

> **服务器现在是「按量计费」，腾讯云规定按量计费实例不能用于备案。**
> 需要先转成包年包月（购买时长 ≥ 3 个月），才能生成备案所需的资源。

所以路径是：**先转计费模式 → 再备案 → 最后切域名**。三步，前两步在腾讯云控制台，第三步我来做。

## 2. 为什么现在不能直接切域名

国内云服务商（腾讯云、阿里云、华为云）都有自动化备案检测系统：

> 若域名未备案且解析到国内服务器 IP，**80/443 端口会被拦截**，
> 请求被跳转到固定提示页，提示需先完成备案。

也就是说，现在把 `claspmoon.cn` 的 A 记录指向 `<服务器IP>`，
访客打开域名看到的是腾讯云的备案提示页 —— **比现在直接用 IP 访问更糟**。

`.cn` 域名由 CNNIC 管理，国内监管对 `.cn` 的备案核查更严格，不建议抱有侥幸心理。

## 3. 备案资格体检

腾讯云官方要求的完整条件（原文摘录）：

> **云服务器（CVM）**：需要先购买腾讯云中国境内有公网 IP 的服务器，
> 计费模式需为**包年包月**，购买包月 3 个月及以上（包含续费）
> 且备案期间剩余有效期需大于（含）1 个月。
>
> **注意**：竞价产品不支持进行备案。按量计费模式的云服务器不支持生成备案授权码。

逐项对照本机情况：

| 要求 | 本机情况 | 判定 |
| --- | --- | --- |
| 中国大陆地域 | 上海 `ap-shanghai-2` | ✅ |
| 有公网 IP | `<服务器IP>` | ✅ |
| 带宽不为 0 | 非 0 | ✅ |
| 计费模式为包年包月 | 按量计费 | ❌ **需转换** |
| 购买时长 ≥ 3 个月 | — | ❌ 转换时选择 |
| 备案期间剩余有效期 ≥ 1 个月 | — | ❌ 转换时保证 |
| 不支持绑定 EIP 备案 | 需在控制台确认公网 IP 类型 | ⚠️ **待确认** |
| 账号实名类型 | 需为「（域名所有者）」个人实名 | ⚠️ **待确认**（控制台昵称显示为「新一鸡」） |

> **个人账号说明**：个人实名账号**不能**生成备案授权码（那是企业账号的功能），
> 但个人账号可以直接用自己名下的服务器备案 —— 本机情况适用这条路径。
> 个人账号一台服务器最多可备案 **5 个**网站/域名，够用。

## 4. 唯一阻塞项：把服务器转成包年包月

### 操作路径（控制台）

1. 登录 [云服务器控制台](https://console.cloud.tencent.com/cvm/index)
2. 找到实例 `<实例ID>`
3. **列表视图**：右侧操作栏 → **更多** → **实例设置** → **按量转包年包月**
   **页签视图**：右上角 **更多操作** → **实例设置** → **按量转包年包月**
4. 在弹窗中设置：
   - **续费时长**：选 **3 个月**或更长（≥3 个月是备案硬要求，建议直接买 1 年更划算）
   - **自动续费**：建议勾上，避免到期导致备案失效
5. 勾选「已阅读并同意按量计费转包年包月规则」→ **立即转换**
6. 跳转到支付页 → **完成支付**

### 注意事项（官方原文要点）

- 转换会产生一个续费订单，**必须完成支付**计费方式变更才生效
- 转换成功并支付后，实例**即刻**按包年包月计费，起始时间为转换成功时间
- 转换后**不支持 5 天内无理由退还** —— 想清楚再点
- 未支付前不要对实例做任何变更（改配置/重装/调带宽/调磁盘），否则订单会失效
- **公网 IP 不会变**（转换只改计费模式，不重建实例），SSH、DNS、部署脚本都不受影响

### 可能遇到的限制

官方列出的不支持转换的情况，对照检查：

| 限制 | 本机是否命中 |
| --- | --- |
| 非按量计费实例 | 否（就是按量） |
| 竞价实例 | 否 |
| 实例网络计费模式为「按带宽使用时长」 | ⚠️ 需在控制台确认 |
| 使用云镜像市场镜像的实例 | ⚠️ 若用了市场镜像需先换镜像 |
| 批量型实例 BC1 / BS1 | 否（S5 机型） |
| 有未完成的转换单 | 否 |
| 设置了定时销毁 | ⚠️ 需在控制台确认 |
| 可用区包年包月剩余配额不足 | 罕见，遇到需先提配额 |

如果点进去提示不能转换，控制台会**直接显示原因**，按提示处理即可。

## 5. 走备案流程（个人备案）

转换支付完成后，就可以开始备案了。

### 5.1 需要准备的材料

| 材料 | 说明 |
| --- | --- |
| 身份证 | 正反面照片，需与域名所有者（（域名所有者））一致 |
| 手机号 | 备案负责人手机，用于接收验证码 |
| 人脸核验 | 腾讯云 App 上做活体核验 |
| 网站名称 | 不能用「XX 博客」以外的敏感词，建议写「流沙」或个人名字相关 |
| 网站服务内容 | 选「个人博客」或「其他」 |
| 域名证书 | 腾讯云控制台可直接下载 |

### 5.2 操作路径

1. 登录 [腾讯云 ICP 备案控制台](https://console.cloud.tencent.com/beian)
2. 选择 **首次备案**
3. 填写主体信息（（域名所有者））、网站信息（claspmoon.cn）
4. 选择备案云资源 —— 选刚转成包年包月的实例
5. 提交腾讯云初审（约 1–2 个工作日）
6. 初审通过后，用腾讯云 App 做人脸核验
7. 腾讯云提交管局审核（各省不同，一般 **7–20 个工作日**）
8. 收到备案号短信 → 完成

### 5.3 备案期间要注意

- **不要**把域名解析指向服务器 —— 未备案访问会被拦截，还可能触发腾讯云的核查
- 站点继续用 `http://<服务器IP>/` 访问，不受影响
- 备案期间服务器**必须保持有效**，不能释放或降配

## 6. 备案通过后：切换到 HTTPS

域名拿到备案号后，A 记录可以解析了。整个切换只有三步。

### 第 1 步：加 DNS 解析

在 DNSPod 控制台给 `claspmoon.cn` 加一条 A 记录：

| 记录类型 | 主机记录 | 记录值 | TTL |
| --- | --- | --- | --- |
| A | `@` | `<服务器IP>` | 600 |
| A | `www` | `<服务器IP>` | 600 |

验证：

```bash
dig +short claspmoon.cn
# 期望输出 <服务器IP>
```

### 第 2 步：服务器切换到域名模式

```bash
ssh <用户>@<服务器>
cd /opt/blog

# 改站点地址（支持多个域名，逗号分隔）
sed -i 's|^SITE_ADDRESS=.*|SITE_ADDRESS=claspmoon.cn, www.claspmoon.cn|' .env
cat .env

# 重建容器，Caddy 会自动申请 Let's Encrypt 证书
docker compose up -d --force-recreate web

# 看日志确认证书申请进度
docker compose logs -f web
```

### 第 3 步：更新站点信息并推送

```bash
# 本地：改 .vitepress/site.ts
# export const SITE_URL = 'https://claspmoon.cn'

git add -A && git commit -m "切换到正式域名 claspmoon.cn" && git push
```

CI 会自动构建部署，RSS、sitemap、og 标签里的链接都会同步更新。

### 验收

```bash
curl -sI https://claspmoon.cn | head -3          # 期望 HTTP/2 200
curl -sI http://claspmoon.cn | grep -i location  # 期望 301 跳 HTTPS
echo | openssl s_client -connect claspmoon.cn:443 -servername claspmoon.cn 2>/dev/null \
  | openssl x509 -noout -subject -dates
```

## 7. 如果不想备案：三个备选

备案要等 1–3 周，如果不想等，可以考虑：

| 方案 | 说明 | 代价 |
| --- | --- | --- |
| **继续用 IP** | 保持现状，`http://<服务器IP>/` 一直可用 | 不方便分享，没有 HTTPS |
| **换中国香港/海外服务器** | 境外服务器无需备案，可自由上 HTTPS | 需要新购服务器、迁移数据；国内访问速度下降 |
| **换到腾讯云 EdgeOne / CDN 境外节点** | 理论上绕过备案 | 实际仍受监管，且配置复杂，不推荐 |

**推荐还是走备案** —— 一次性投入，之后域名、HTTPS、微信分享、搜索引擎收录都正常，
而 `.cn` 域名已经买了，不用反而浪费。
