# Go

Go 的设计目标是「工程上够用」——语法少到可以一周学完，剩下的时间都花在读懂并发和工程实践上。

## 这个方向适合谁

- 写过 Python 或 Java，想找一个部署简单、并发直观的语言
- 需要写 HTTP 服务、CLI 工具、运维脚本
- 受够了「环境依赖装不起来」这件事（Go 编译出的是单个静态二进制）
