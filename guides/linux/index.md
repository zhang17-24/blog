## 先记住三件事

1. **`man <命令>` 永远是最权威的文档**，比任何教程都准
2. **`Ctrl + R` 反向搜索历史命令** —— 这个快捷键能省下大量打字
3. **危险命令敲完先别回车**，看清楚路径再按

::: danger 三条必须警惕的命令
```bash
rm -rf /            # 绝对不要跑，也绝对不要复制网上的这类命令
chmod -R 777 /      # 把整个系统的权限全打开
> /dev/sda          # 直接往磁盘设备写，会毁掉分区表
```

看到网上教程里出现这些，先停下来想想它到底在干什么。
:::
