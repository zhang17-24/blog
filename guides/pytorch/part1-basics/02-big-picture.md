## 一、深度学习到底在做什么

一句话：**给神经网络看很多张图片，告诉它每张图是什么，它就不断调整内部的数字参数，让猜错的次数越来越少。**

拆开来看，一次完整的训练是这样：

```
① 准备数据      →  第2、3章
   把 6 万张衣服图片读进来，转成模型能吃的格式，打乱，分成一批批

② 搭模型        →  第 4 章
   一个函数：输入一张图，输出 10 个数字（每个类别一个分数）

③ 前向传播      →  第 4 章
   拿一批图片喂进模型，得到 10 个分数

④ 算损失        →  第 6 章
   拿模型的分数和真实标签比，算出一个「错得多严重」的数

⑤ 反向传播      →  第 5 章
   自动算出「每个参数该往哪个方向调、调多少」

⑥ 更新参数      →  第 6 章
   按上面算出的方向把参数拧一点点

⑦ 重复 ③④⑤⑥   →  第 6 章
   一遍数据 = 1 个 epoch。重复 5~10 轮
```

**第 ⑤ 步是 PyTorch 的全部卖点。** 前三四步任何深度学习框架都有，但「自动求梯度」这件事只有 PyTorch 做得又准又快又好用。

## 二、这个项目用的数据

**FashionMNIST** —— Zalando（德国电商）的衣服图片，数据集公开免费。

| 项目 | 值 |
|---|---|
| 训练集 | 60,000 张 |
| 测试集 | 10,000 张 |
| 图片大小 | 28 × 28 像素 |
| 颜色 | 灰度（每个像素 0~255 的一个数） |
| 类别数 | 10 |

10 个类别（标签 0~9）：

```
0: T-shirt/top    T恤      5: Sandal凉鞋
1: Trouser       裤子      6: Shirt        衬衫
2: Pullover      套头衫    7: Sneaker      运动鞋
3: Dress         连衣裙    8: Bag          包
4: Coat          外套      9: Ankle boot   踝靴
```

为什么用这个数据集？因为它是 **MNIST 的升级版**——原来 MNIST 是手写数字（太简单了，深度学习早就能 99%+，没有研究价值），FashionMNIST 复杂一点但仍然很轻，是深度学习领域的「Hello World」。

## 三、模型长什么样

这套教程的模型是一个最简单的全连接网络：

```
输入 (28×28=784 个像素)
        ↓
   [Flatten]  把 28×28 的图压成一维的 784 个数
        ↓
   [Linear 784→512]  乘权重、加偏置，变成 512 个数
        ↓
   [ReLU]           小于 0 的都砍成 0
        ↓
   [Linear 512→512] 再变一次
        ↓
   [ReLU]           再砍一次
        ↓
   [Linear 512→10]  变成 10 个分数
        ↓
   输出 (10 个类别的分数)
```

**为什么中间要砍成 0（ReLU）？**

不加激活函数的话，无论叠多少层Linear，计算出来都还是一次线性变换，等价于**一个** Linear——叠了也白叠。ReLU 引入非线性，才让网络能拟合复杂关系。

**为什么最后是 10 个数而不是 1 个 0~1 的概率？**

因为神经网络喜欢用「无约束的实数」做中间计算（不会因为反复乘除而数值爆炸）。最后一步再用 Softmax 把这 10 个数转成概率。这也是为什么损失函数要用 `CrossEntropyLoss` 而不是 MSE——它内部已经帮你做了 Softmax。

## 四、训练结果长什么样

跑完 5 轮，你大概会看到：

```
Epoch 1:  Accuracy: 45.9%
Epoch 2:  Accuracy: 52.3%
Epoch 3:  Accuracy: 57.8%
Epoch 4:  Accuracy: 62.9%
Epoch 5:  Accuracy: 64.9%
```

**65% 是什么水平？** 猜对一张衣服图的类别，有 10 个选项，纯瞎猜是 10%。65% 算是一个「模型确实学到了东西但还没学透」的水平。

作为参照：

| 水平 | 准确率 |
|---|---|
| 瞎猜 | 10% |
| **本教程的模型** | **~65%** |
| 加卷积层（CNN） | ~90% |
| 人类 | ~94% |

本教程故意不用卷积，因为**全连接网络更容易看懂**。你要学的是流程和原理，卷积留到下一阶段。

## 五、你现在应该知道的三件事

1. **深度学习的流程是固定的**——不管图片、文字还是声音，都是「准备数据 → 搭模型 → 前向 → 算损失 → 反向 → 更新参数」这个循环。学会这一次，换个数据集只是换第①步。

2. **PyTorch 的核心能力是「自动求梯度」**。第 5 章是整套教程的重点，其他章节都是准备工作。

3. **90% 的报错是 shape 不对**。养成习惯：报错先 `print(x.shape)`。

## 六、动手看看

在跑任何 PyTorch 代码之前，先用纯 NumPy 感受一下「神经网络其实就是一堆矩阵乘法」：

```python
import numpy as np

# 假装这是模型：输入 4 个特征，输出 3 个分数
W1 = np.random.randn(4, 8)   # 权重
b1 = np.zeros(8)              # 偏置

x = np.random.randn(4)        # 一条输入
h = np.maximum(x @ W1 + b1, 0) # 线性变换 + ReLU
print(h.shape)                # (8,)  中间层输出了 8 个数

W2 = np.random.randn(8, 3)
logits = h @ W2               # 第二个线性层
print(logits.shape)           # (3,)  最终输出 3 个分数

probs = np.exp(logits) / np.exp(logits).sum()  # Softmax
print(probs, probs.sum())     # 概率，sum 恰好是 1
```

**这就是一个两层网络。** PyTorch 做的事一样，只是自动帮你算导数、在 GPU 上跑、并且能扩展到几百万个参数。
