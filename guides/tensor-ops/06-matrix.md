# 6. 矩阵运算：逐元素 / 矩阵乘

![两种乘法](/figs/tensor-ops/08-two-multiplications.png)

```python
A = torch.tensor([[1., 2., 3.], [4., 5., 6.]])       # (2,3)
B = torch.tensor([[10., 20., 30.], [40., 50., 60.]]) # (2,3)

print("A * B    shape", tuple((A * B).shape))     # 逐元素
print(A * B)
print("A @ B.T  shape", tuple((A @ B.T).shape))   # 矩阵乘
print(A @ B.T)
```

```
A * B    shape (2, 3)
tensor([[ 10.,  40.,  90.],
        [160., 250., 360.]])

A @ B.T  shape (2, 2)
tensor([[140., 320.],
        [320., 770.]])
```

## 三个运算符

| 运算符 | 名称 | 形状变化 | 用途 |
|---|---|---|---|
| `*` | 逐元素乘 | **不变**（要求形状可广播） | 缩放、门控、mask |
| `@` | 矩阵乘 | 内维消掉 | 线性层、注意力 |
| `torch.dot` | 内积 | → 标量 | 只对 1 维 |

## 矩阵乘的形状规则

![matmul 形状](/figs/tensor-ops/11-matmul-shape.png)

```
(..., m, k)  @  (..., k, n)  ->  (..., m, n)
```

**记忆口诀：「内维消掉，外维保留」**——最后两个维度是 `(m,k)` 和 `(k,n)`，中间的 `k` 必须相等，算完就消失。

**`...` 表示可以有任意多个 batch 维度**：

```python
X = torch.randn(8, 4, 5)      # 8 个 (4,5) 矩阵
W = torch.randn(5, 3)         # (5,3)
print((X @ W).shape)          # (8, 4, 3)
```

**这就是批量矩阵乘**——一次算 8 个矩阵乘法。

## 想看相似度怎么写

`A @ B` 内维不匹配（`3 ≠ 2`）时，如果目的是「算 A 和 B 各行之间的相似度」：

```python
print((A @ B.T).shape)   # (2,2) —— 2×2 的相似度矩阵
```

**为什么转置？** 因为相似度是「行与行的点积」，需要让两个张量的**特征维**（最后一维）对齐。`(2,3) @ (2,3).T = (2,3) @ (3,2) = (2,2)` ✓
