# 所有权

Rust 最核心的概念，也是最多人卡住的地方。这份笔记只记录我自己理解它的路径。

## 三条规则

1. 每个值都有一个**所有者**（owner）
2. 同一时刻只能有**一个**所有者
3. 所有者离开作用域时，值被**丢弃**（drop）

## 移动

```rust
let s1 = String::from("hello");
let s2 = s1;
// s1 已经失效
```

`String` 在栈上存「指针 + 长度 + 容量」，字符数据在堆上。
赋值时复制栈上的三个字段，同时把 `s1` 作废。

这不是浅拷贝（会双重释放），也不是深拷贝（有运行时开销），而是**移动**。

## 借用

**要么任意多个不可变借用，要么恰好一个可变借用。**

```rust
let mut v = vec![1, 2, 3];
let a = &v;
let b = &v;
println!("{a:?} {b:?}"); // a、b 的最后一次使用
let c = &mut v;          // 到这里 a、b 的借用已经结束
c.push(4);
```

借用结束于**最后一次使用**，而不是作用域结尾 —— 这就是 NLL。

## 常见坑

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| `borrow of moved value` | 值被移动了 | `clone()`，或改成传引用 |
| `cannot borrow as mutable` | 同时存在不可变借用 | 缩短借用范围，或调整使用顺序 |
| `does not live long enough` | 借用的东西先被释放 | 把数据的所有者提到更外层 |

## 该不该用 Rc / RefCell

先问自己：真的需要共享所有权吗？真的需要在共享的同时修改吗？

大部分时候答案是「不需要」。把数据拆开、把所有权理清楚，
比堆一层 `RefCell` 更清楚。
