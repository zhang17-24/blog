换过七个笔记软件之后我才明白，问题不在工具，在于我从来没回去看过。

## 换过的那些

印象笔记、Notion、Obsidian、语雀、飞书文档、Apple Notes、以及一个自己写的
纯文本 + grep 的方案。

每一个都用了至少三个月。每一个都在某个时刻让我觉得「这次对了」。

## 真正的问题

去年整理硬盘的时候，我导出了所有笔记平台的备份，放在一起看：

- 印象笔记 400 多篇，最后修改时间集中在 2018 年
- Notion 200 多篇，一半是各种模板和看板
- Obsidian 100 多篇，双链画得挺漂亮

加起来 700 多篇。**我真正回头读过的大概不到 20 篇。**

问题从来不是「哪个软件更好」，而是「我写完就不看了」。

## 现在的做法

规则很简单：

1. 所有笔记是 `.md` 文件，放在一个 git 仓库里
2. 目录就是分类，不搞标签体系
3. 每次要查东西，先 `grep -r "关键词" .`
4. 每周五花二十分钟，随便翻翻这周改过什么

第 4 条是关键。以前我也定过「每周回顾」的计划，但那时候笔记散在云上，
回顾的成本是「打开 App、等同步、翻列表」。现在是 `cd notes && git log --since=1.week`，
一条命令。

## 一些副作用

- 开始写得更短了。反正要复读，写得啰嗦自己受罪
- 开始删东西了。看到三年前的废话，顺手就删了
- 搜索变快了。`grep` 比任何笔记软件的搜索都快

工具确实重要，但它解决的问题是「查找」，不是「回顾」。
回顾得靠一个能坚持下去的习惯 —— 而习惯需要摩擦足够小。
